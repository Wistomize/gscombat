## Purpose

定义已审阅武器在固定单动作场景中的自动准备、必要用户选择和对比行为，确保实际装备、完整武器列表与单候选更新遵循同一资格、来源和属性计算规则，同时保留旧配置及前后台边界，不扩展为轮转模拟。

## ADDED Requirements

### Requirement: 三星至五星使用统一比较资格

系统 MUST 将已支持且符合角色武器类型的三星、四星、五星武器纳入比较，不得仅因三星稀有度排除候选。三星与四星 MUST 默认精炼 5、五星默认精炼 1，并支持合法精炼选择；完整列表与单候选更新 MUST 使用相同资格。一/二星及既有明确排除项不纳入本次比较范围。

#### Scenario: 三星弹弓参与完整和增量比较

- **WHEN** 用户计算弓角色指标且弹弓符合已支持候选资格
- **THEN** 完整武器列表包含默认精炼 5 的弹弓，其适用箭矢按已确认增伤/减伤选择计算
- **AND** 更改该行合法精炼或专属条件后可以单候选更新，与同条件完整比较结果一致

#### Scenario: 不兼容武器不因扩展星级而入榜

- **WHEN** 用户计算单手剑角色指标
- **THEN** 已支持的三星单手剑可参与比较，三星弓仍不入榜

#### Scenario: 宗室系列明确排除但保留已有装备

- **WHEN** 用户请求完整武器比较或宗室系列的单候选比较
- **THEN** 完整列表不包含宗室长剑、宗室大剑、宗室猎枪、宗室长弓和宗室秘法录，单候选请求返回可读的4xx错误
- **AND** 已装备这些武器的角色配置仍可读取和计算，不因比较资格排除而删除或替换其武器

### Requirement: 实际装备与候选采用相同规则

系统 MUST 为实际装备与候选使用相同的已确认武器规则。武器、等级、突破、精炼、队伍、指标及有效选择全部相同时，结果 MUST 一致；候选默认值 MUST NOT 覆盖有效的必要手选。

#### Scenario: 遗祀玉珑实际装备与候选一致

- **WHEN** 用户比较遗祀玉珑并随后以相同等级精炼实际装备，其他场景条件不变
- **THEN** 两次结果均包含已确认有效期内的生命和精通效果，数值一致
- **AND** 当前武器以相同配置比较自身时提升比例为零

### Requirement: 准备资格与命中时前后台分离

系统 MUST 分开判断来源能否准备、退出前台是否保留以及谁能受益；多人反应贡献计算 MUST 保持同一个实际前台身份。用户确认的武器准备假设 MUST 只影响该条款，不能成为全场景真实战斗事实。

#### Scenario: 四风原典后台不叠层

- **WHEN** 装备者的所选指标为后台且旧配置保存了四风四层
- **THEN** 层数增伤为零，常驻面板仍保留，前台层数控件不显示

#### Scenario: 武器自用默认不传播成全队状态

- **WHEN** 苇海信标按确认口径默认无盾
- **THEN** 只按该武器规则计算相关效果，不删除队友合法护盾能力或其他武器的独立资格

### Requirement: 治疗与反应能力必须匹配来源和对象

充分治疗准备 MUST 先验证适用来源及治疗对象；自身反应触发条款 MUST 验证装备者在当前队伍的触发能力，不能只看队伍元素或反应类直伤标签。魔导强化 MUST 同时符合本轮确认的装备者资格与队伍条件。

#### Scenario: 海渊终曲不能借队友自疗清契

- **WHEN** 队伍唯一治疗能力只作用于另一名队员自身
- **THEN** 海渊终曲不计清契转攻击，但装备者合法开 E 的攻击加成保留
- **AND** 加入能治疗装备者的来源后，按候选最终生命的 25% 契量完整清除并依精炼换算、封顶

#### Scenario: 反应类伤害不代替亲自触发

- **WHEN** 武器要求装备者触发指定反应，而装备者只能造成该反应类型的直伤
- **THEN** 仅有直伤能力不足以开启该条款；明确接受反应伤害的另一条款仍可独立满足

### Requirement: 自动层数遵循声明机会而非虚构历史

系统 MUST 区分战技施放次数、有效命中次数及反应触发，按确认窗口和间隔准备可达层数。默认准备 MUST NOT 额外制造技能伤害事件或倒灌明确的首次触发命中；明确用户特例按确认口径处理。

#### Scenario: 一次施放多次命中

- **WHEN** 装备白湖冬羽的角色有八秒内三次间隔合格的 E 命中能力
- **THEN** 默认可得三层攻击及满层星烁暴伤；只有一次命中能力时仅一层
- **AND** 不因一次施放多次命中就给要求多次施放的效果同样层数

#### Scenario: 祭礼重置仅改变准备机会

- **WHEN** 祭礼武器的合法命中可准备一次冷却重置
- **THEN** 相关叠层查询纳入该机会，但所选单次 E 伤害不因此翻倍

### Requirement: 候选重算属性与效果来源

更换武器 MUST 重算候选的基础属性、派生能力、合法属性转换和受影响队伍效果。系统 MUST 只替换该装备者的武器来源，保留独立队友来源；普通增伤、特殊反应增伤及暴伤 MUST 按适用类别进入公式，有效暴击率不得超过 100%。

#### Scenario: 薙草之稻光与绝缘联动

- **WHEN** 候选武器增加爆发后的充能且角色装备绝缘
- **THEN** 候选结果重新计算充能、合法转攻击及绝缘增伤，不沿用原武器最终面板

#### Scenario: 两个相同团队武器来源

- **WHEN** 主角色和队友原先均装备流浪的晚星，主角色改为其他武器
- **THEN** 主角色原武器贡献移除，队友武器贡献按自己的属性保留，不重复也不误删

### Requirement: 只展示必要选择并保持单行对比

武器对比 MUST 保持一把一行，保留图标、名称、精炼、期望伤害和提升比例，仅显示已确认且当前适用的必要条件控件。自动规则 MUST NOT 增加开关、状态卡片或逐行解释面板。

#### Scenario: 半血与弹弓选择

- **WHEN** 用户选择护摩之杖或装备弹弓的适用箭矢指标
- **THEN** 护摩半血默认关闭；弹弓只提供增伤/减伤且默认增伤，不存在中性状态

#### Scenario: 无效与不适用选择

- **WHEN** 新请求提交越界层数、不属于目标武器的选项或不在队伍中的接力对象
- **THEN** 返回可读的 4xx 错误，不产生伪造效果或 HTTP 500
- **AND** 合法旧选择因切换前后台暂时不适用时不绕过资格，也不破坏保存的角色配置

#### Scenario: 辅助指标展示实际装备的必要选择

- **WHEN** 用户选择合法辅助指标，实际装备存在影响来源属性的必要武器选择
- **THEN** 页面从相同武器选择目录展示并提交该选择，目录与辅助求值使用相同的已知或未知前台身份
- **AND** 纯伤害控件不显示；复用伤害动作的辅助指标以可选辅助指标标识区分，旧伤害请求保持兼容
- **AND** 这不增加辅助指标武器对比功能

### Requirement: 候选专属调整不修改基准

候选精炼及武器专属条件的修改 MUST 只更新该候选结果与排序，不触发全量武器重算或改写基准；全局敌人、实际前台、队伍或共同命中场景变化 MUST 使相关旧结果失效。

#### Scenario: 连续调整一行

- **WHEN** 用户连续改变一把候选武器的精炼及半血选项
- **THEN** 服务仅评估当前基准与目标候选，网页只接受最新请求世代的返回
- **AND** 其他行及基准不被该候选的半血假设污染

### Requirement: 旧选择兼容且不覆盖新自动规则

系统 MUST 接受仍受支持的旧场景，并以可追溯映射保留有效手选。已自动化的旧武器效果选择 MUST 按新资格重算，不能成为强制开启或重复叠加的后门；兼容处理不得删除无关 Build 或队友条件。

#### Scenario: 服务升级后不混合新旧报告

- **WHEN** 单候选响应的分析语义版本不同于当前完整报告
- **THEN** 客户端拒绝合入该行并提示重新完整计算，即使两者的基准值恰好相同
- **AND** 用户角色配置不被删除，未携带新增可选版本字段的旧接口响应仍可读取

#### Scenario: 旧赦罪层数不再强制开启

- **WHEN** 非克洛琳德角色的旧场景保存赦罪满层选择
- **THEN** 仍能读取该场景，但按确认规则计零层；克洛琳德自动满层
- **AND** 其他武器的有效手选与用户角色库保持完整

### Requirement: 保留计算范围与特殊武器约束

独立武器追加伤害、回能和攻速 MUST 按确认记录排除于当前单次伤害，同命中基础加值及合法能力作用不得随之删除。特殊进度、共鸣及精炼 MUST 分开处理，不能生成已知非法等级组合。

#### Scenario: 忽略治疗数值但保留治疗能力

- **WHEN** 队友装备可合法进行团队治疗的试作金珀
- **THEN** 其治疗不加到当前伤害总值，但能在匹配对象和准备条件下作为受疗武器的能力来源

#### Scenario: 星锋剑旅行者默认

- **WHEN** 任一受支持元素的旅行者装备星锋剑
- **THEN** 使用共鸣五级和当前经核实可解锁元素全解锁的默认规则，不显示进度选择
- **AND** 武器为90级、六突破、精炼三阶；共鸣五级不得解释为精炼五阶或五种已解锁元素
