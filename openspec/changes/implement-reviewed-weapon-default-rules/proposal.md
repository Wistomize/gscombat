## Why

233 把武器的工具规则已完成用户确认，但当前声明仍混合手选效果、候选专用默认值和自动能力判定，不能保证实际装备与武器对比一致。本次将确认规则落实到现有权威计算链路，优先消除基准/候选差异、来源串用和前后台误判。

本变更涉及共享计算语义、条件请求兼容和至少三个 workspace，触发强制 OpenSpec。用户已授权实施；提交、推送和部署仍需另行授权。

## What Changes

- 以 [233 把确认记录](../../../docs/plans/2026-09-17-weapon-effect-review.md) 为规则依据，先形成逐武器差异清单，再按能力依赖分批迁移。已经正确的声明不重写。
- 实际装备、完整比较、单候选比较共用自动默认、必要手选和来源资格；候选必须重算自身面板与关联队伍效果，不改变实际前台。
- 复用效果生命周期与角色/装备能力，补齐本轮需要的治疗对象、精确反应资格、命中机会及叠层查询；不建立战斗时间模拟器。
- 只保留确认记录指定的条件控件；武器对比仍一把一行。改某行精炼或专属条件只更新该候选，不能重新求整个榜单。
- 兼容已有场景的武器效果选择，已自动化的旧开关不再绕过资格；不能静默清空用户配置或误删队友效果。
- 独立武器追加伤害按用户口径排除，同命中基础加值、属性转换、治疗/护盾指标中适用属性仍保留。

## Capabilities

### New Capabilities

- `analysis/weapon-effect-defaults`：统一武器默认准备、必要条件选择、反事实一致性、增量交互及旧输入兼容。

### Modified Capabilities

无。现有单一权威链路、实体所有权及版本化工作区要求保持不变；新规格细化武器效果默认规则。

## Impact

- 主要涉及 `packages/content`、`packages/analyzer`、`packages/contracts`、`apps/api`、`apps/web`。`packages/calculator` 保持通用公式边界，原则上不修改；`packages/game-data` 不更新快照；小程序只验证共享契约兼容，不扩展页面。
- API 保留完整分析与单候选比较端点，按需添加可选候选条件字段及目录选项元数据；不引入新的计算服务或跨用户结果缓存。
- 兼容策略在解析边界映射旧 ID，自动化旧条件由新规则重新派生；有效手选值保留。默认不更改 CharacterBuild、工作区 schema version 或 SQLite 表结构。
- 安全与授权不变；不读取私人测试账号。最终发布需要用户另行授权，API/Web 同版本部署并保留数据库备份。
- 非目标：7.1 数据更新、循环/概率/移动距离模拟、圣遗物再审查、角色命座全面修复、辅助指标武器排名，以及未确认的武器效果。掠食者、降临之剑、落霞沿用排除口径。
- 233 是本轮规则覆盖数，不代表单个角色的对比行数；按用户修正，比较池扩展为已支持且武器类型匹配的三/四/五星。三星与四星默认精炼 5，五星默认精炼 1，保留合法精炼选择；一/二星和既有排除项不纳入。
- 后续用户裁决：宗室长剑、大剑、猎枪、长弓、秘法录全部不列武器对比。保留实体与已有装备配置兼容，不在本轮扩展宗室多段暴击清层模型。
