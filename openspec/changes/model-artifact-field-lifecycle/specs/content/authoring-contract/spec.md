## ADDED Requirements

### Requirement: 角色能力声明可追溯且有明确范围

可被效果查询的角色能力 MUST 由角色内容维护，注明技能来源、作用对象、来源站位和必要配置条件；不得用无来源的全队布尔值代替。能力条件 MUST 与具体效果的默认满层策略分开，保持同一能力可被多个效果复用而不互相改变含义。

#### Scenario: 自身扣血声明

- **WHEN** 维护角色仅对自身生效的主动扣血技能
- **THEN** 声明明确限制受益对象为自身，保留技能来源
- **AND** 其他效果不能把它解释为全队扣血或受到攻击

#### Scenario: 命座解锁能力

- **WHEN** 一个能力仅在指定命座或技能状态下可用
- **THEN** 声明包含该条件，不对所有配置无条件启用

#### Scenario: 有限准备窗口内的战技施放资格

- **WHEN** 效果需要按固定十秒内可施放的战技次数推导默认层数
- **THEN** 技能的冷却、充能与多次施放依据留在角色实体，武器重置及其触发限制留在武器实体，由分析层按实际配置组合
- **AND** 声明区分再次施放与同次战技的持续/多段命中，不维护效果专用的中央角色名称名单

#### Scenario: 有限准备窗口内的合法命中资格

- **WHEN** 效果按战技命中机会而非施放次数推导层数
- **THEN** 复用角色实体的持续/多段命中机制与有效配置，结合效果触发间隔判定可贡献次数
- **AND** 不把一次施放限制成一次命中，也不把同时多目标命中或不足间隔的伤害包解释成多个有效触发

#### Scenario: 课业资格不是账号任务完成度

- **WHEN** 内容效果需要判断装备者是否完成魔女的课业
- **THEN** 按角色是否拥有该机制判断，有机制默认已完成，无机制不具备资格
- **AND** 不新增账号任务进度字段或用户完成度选择，不借用队友课业资格，不将魔导·秘仪组队状态等同于个人课业资格

### Requirement: 圣遗物站位与持续覆盖可审计

所有 inventory 套装 MUST 有条款级覆盖记录；已支持的伤害、治疗和护盾条款 MUST 有明确的触发、保持与受益范围分类及语义依据。常驻效果可以明确声明无站位限制，不得把缺少声明或仅有文案当作已审核。未支持条款 MUST 保持真实状态及原因，不因存在基础加成而标为整套完成。

#### Scenario: 黄金剧团旧排除失效

- **WHEN** 系统已经支持后台指标而覆盖记录仍以“所有指标前台”为由排除后台条款
- **THEN** 覆盖检查报告该条款需要更新，不接受此理由作为完成证据

#### Scenario: 辅助效果不在伤害目录

- **WHEN** 审查被怜爱的少女或千岩牢固
- **THEN** 同时计入已支持治疗、受治疗和盾强条款
- **AND** 不因为伤害效果清单为空或不含该属性就误判未实现

#### Scenario: 不支持的累计机制

- **WHEN** 审查海染砗磲或昔时之歌四件套
- **THEN** 明示累计机制尚未支持，不自动增加虚构伤害
