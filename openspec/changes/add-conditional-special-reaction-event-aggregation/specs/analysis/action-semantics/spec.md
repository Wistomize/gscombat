## ADDED Requirements

### Requirement: 条件化特殊反应事件

动作内特殊反应事件 MUST 可声明来源角色最低命座，并在求值时根据当前角色 Build 的累积命座动态启用。系统 MUST 允许同一动作同时声明实际星扩散反应事件与角色直接造成、视为星扩散反应伤害的独立事件；两类事件 MUST 分别使用各自适用的既有公式，不得把独立事件的元素精通倍率当作实际反应的等级基础伤害。

#### Scenario: C0 不生成 C1 独立事件

- **WHEN** 所选动作包含最低一命才启用的独立星扩散事件，而来源角色 Build 为 C0
- **THEN** 系统不求值、不展示且不计入该事件
- **AND** 同一动作中无命座门槛的事件仍正常求值

#### Scenario: C1 累积启用独立事件

- **WHEN** 同一来源角色 Build 为 C1 或更高命座，且动作声明的辉映与印记消耗前提成立
- **THEN** 系统求值一次 `400% × 来源角色最终元素精通`的独立星扩散事件
- **AND** 该事件单独完成特殊反应增伤、暴击、抗性和擢升结算

### Requirement: 特殊反应效果可限定到动作内事件

特殊反应阶段效果 MUST 可按稳定动作内事件标识筛选。声明了事件范围的效果 MUST 只进入匹配事件的公式轨迹；未声明事件范围的既有效果 MUST 保持当前动作级适用行为。

#### Scenario: C1 后置固定伤害只进入触发反应

- **WHEN** C1 梦见月瑞希的星扩散联动动作求值，且选中的实际星扩散触发事件消耗了 C1 印记
- **THEN** 系统在该次触发反应的精通与反应增伤之后、暴击之前加入 `550% × 梦见月瑞希最终元素精通`
- **AND** 该值不得进入同一动作中的 `400%`或 `1000%`独立星扩散事件

#### Scenario: 不满足命座或印记条件

- **WHEN** 来源角色低于 C1，或所选动作未声明 C1 印记由该次实际星扩散消耗
- **THEN** 系统不应用 `550% × 元素精通`后置固定伤害

### Requirement: 实际星扩散与视为星扩散事件保持公式身份

实际星扩散事件 MUST 使用已维护的星扩散触发系数、角色等级基础伤害和参与者聚合规则；角色直接造成且视为星扩散的事件 MUST 使用其声明的角色属性倍率和直接星扩散系数。两类事件 MUST NOT 在基础伤害阶段互相替代。

#### Scenario: 同一动作包含两类星扩散事件

- **WHEN** 一个动作先产生实际星扩散触发反应，随后产生基于角色最终元素精通的独立星扩散伤害
- **THEN** 前者按实际反应参与者公式求值，后者按声明的元素精通倍率求值
- **AND** 每个事件的轨迹明确其公式身份与基础伤害来源
