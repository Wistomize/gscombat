## 公共链路与兼容性

- 追加事件仍由同一场景求值；武器反事实、词条边际、有效词条不另建公式。
- 概率轨迹新增可选 `trigger_probability` 阶段。技能本体倍率与完整命中概率不再混成一个系数，前端明确展示最后一次加权。
- 比例精通分享仍分分享前/后两阶段；自身装备、团队装备、角色贡献互斥，避免重复或递归放大。
- API 对未解锁的公开伤害/辅助指标返回 400 资格错误，保留真正计算失败的 500，不通过宽泛捕获掩盖错误。
- 无需迁移用户 Build 或工作空间；玛薇卡旧无反应 ID 可继续读取。公开目录仅删除 4 个重复入口。
- 未声明前后台的动作不自动视为后台。后续确认某旧技能可后台触发时，应显式补 `fieldPresence: off_field`，而不是默认给予梦浮增益。
