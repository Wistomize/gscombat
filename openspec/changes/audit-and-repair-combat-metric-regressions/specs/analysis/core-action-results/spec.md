## ADDED Requirements

### Requirement: 星扩散直伤与反应指标分离

系统 MUST 将梦见月星扩散直伤与风元素反应伤害分别展示，不混入普通风伤或冰风旋。直伤 MUST 只合计1000%精通天赋段与C1条件成立时的400%精通段，不执行贡献加权；550%精通的C1加算 MUST 仅进入反应指标的后置固定加算，且不重复应用到全部贡献者。

#### Scenario: 同一 C1 配置选择两个指标

- **WHEN** 梦见月在梦浮、辉映与标记触发可用的固定前提下分别计算直伤与反应指标
- **THEN** 直伤只出现两段精通倍率伤害，反应只出现一次参与者聚合事件
- **AND** 直伤不包含550%加算，反应不包含1000%或400%直伤段
- **AND** 普通扩散和治疗指标保持可用，旧联动ID仍可请求并以明确的直伤名称展示修正后的语义

#### Scenario: 固定冰底的贡献者与前台身份

- **WHEN** 梦见月作为触发者，队伍包含冰元素挂冰者与其他辅助
- **THEN** 风反应仅计算触发者及预设具有有效冰附着的冰队友贡献，其他辅助不凭入队取得贡献权重
- **AND** 梦浮的团队增益对合格贡献者仍生效，属性求值不会把他们误认为当前前台

### Requirement: 星扩散元素限定贡献与手动风旋等级

系统 MUST 按已确认的项目口径计算星扩散：风反应60%位置限风角色；冰反应60%位置限冰角色、30%位置限风角色；剩余位置从未选中的有效参与者按本次伤害选择。各暴击组合 MUST 分别排序后求期望；同一角色不得重复占位，缺失元素位置贡献为零，不向其他元素转让。月反应与直伤公式 MUST 保持原规则。

#### Scenario: 冰角色贡献大于风角色

- **WHEN** 冰参与者的折前伤害超过风参与者
- **THEN** 风反应仍由风参与者占60%，冰参与者不能挤占该位置
- **AND** 冰风旋由冰参与者占60%、风参与者占30%，暴击仅影响各限定候选内部选择

#### Scenario: 风旋等级选择与公式

- **WHEN** 用户选择梦见月反应星扩散·冰指标
- **THEN** 提供1–6级选择且默认6级，1–2级使用反应系数2，3–6级使用3
- **AND** 结果只含一次冰风旋，轨迹展示等级与系数，不合并风触发、1000%/400%直伤或C1的550%追加
- **AND** 超出范围、非整数或未声明参数引用被拒绝，武器和词条分析保留相同手动等级

#### Scenario: 对应元素贡献者缺位

- **WHEN** 冰风旋的固定参与者中没有冰角色
- **THEN** 60%冰位置贡献为零，风角色仍只占30%位置，不被提升到60%

### Requirement: 公开指标资格与变体一致

命座专属指标 MUST 只在相应命座解锁后可选，直接请求未解锁指标 MUST 返回明确资格错误，不能返回伪零伤害。无反应变体 MUST 保留原动作的适用属性、固有天赋、命座与伤害倍率，仅移除所声明的元素反应；同义入口不得公开为多个互相矛盾的结果。

#### Scenario: 未解锁的莱欧斯利满命指标

- **WHEN** C0 至 C5 配置请求仅在 C6 存在的强化重击指标
- **THEN** 前端不提供该专属选项，直接求值返回明确的命座资格错误
- **AND** HTTP 入口将未解锁指标报告为 400 输入错误，不包装成 500 服务错误

#### Scenario: 玛薇卡 C6 无反应变体

- **WHEN** 相同配置通过当前或兼容的旧无反应指标 ID 计算同一 C6 技能伤害
- **THEN** 得到相同的非伪零结果及一致的命座倍率来源
- **AND** 不因 ID 后缀差异漏掉基础伤害项

### Requirement: 指标使用正确属性与累计数值来源

伤害、治疗、护盾与属性增益指标 MUST 使用该指标的明确缩放属性和天赋参数，并应用与其相关的所有已解锁命座和固定状态增益。属性轨迹、伤害轨迹和边际收益 MUST 反映相同取值；参数值存在于快照中并不足以证明其属于该动作。

#### Scenario: 莱依拉生命值伤害

- **WHEN** 其他条件固定，增加莱依拉 Q 星光弹来源角色的生命值或攻击力
- **THEN** 生命值增加影响其生命倍率基础伤害，而纯攻击力增加不影响该基础伤害

#### Scenario: 迪奥娜治疗与生命值

- **WHEN** 其他条件固定，增加迪奥娜 Q 单跳治疗的生命值或攻击力
- **THEN** 治疗按生命值倍率变化，不按攻击力倍率变化

#### Scenario: 早柚 C6 治疗上限

- **WHEN** 早柚已解锁 C6，计算符合 C6 条件的不倒貉貉单跳治疗
- **THEN** 将 `min(3 × 元素精通, 6000)` 作为正确阶段的治疗基础项参与计算
- **AND** C0 至 C5 不取得该 C6 基础项，轨迹明确其来源和上限

#### Scenario: 林尼礼花术弹参数

- **WHEN** C6 林尼以配置普攻 10 级计算重奏礼花术弹
- **THEN** 使用累计命座后的有效天赋等级读取礼花术弹伤害参数，再应用 C6 的对应倍率
- **AND** 不把猫猫帽生命继承比例当作伤害倍率

#### Scenario: 队友装备精通参与来源转换

- **WHEN** 玛海菈或流浪的晚星的来源角色受到另一个千夜浮梦装备者的合格固定精通增益
- **THEN** 来源精通与后续精通转攻击必须包含该装备增益，不能因属性求值拆分而遗漏
- **AND** 自身装备贡献只计一次，比例精通分享仍使用非递归的分享前快照

#### Scenario: 结果修正同步进入收益分析

- **WHEN** 已修复指标执行武器更换或圣遗物词条边际计算
- **THEN** 基线与候选均使用修复后的同一套事件和属性语义
- **AND** 对无关属性不产生虚假的伤害或治疗收益

#### Scenario: 艾梅莉埃 C6 的燃烧目标前提

- **WHEN** 艾梅莉埃计算 C6 普攻或重击，明确选择目标正在燃烧且已解锁精馏
- **THEN** 增伤区包含 `min(实际攻击力 × 0.00015, 0.36)`，攻击变化后重新取值
- **AND** 未选择此前提时不自动应用，不与已经预设燃烧的二阶柔灯指标重复叠加
