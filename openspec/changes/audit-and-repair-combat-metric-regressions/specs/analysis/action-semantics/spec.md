## ADDED Requirements

### Requirement: 未生效事件与伤害加算隔离

系统 MUST 根据命座、触发条件和事件资格决定一次命中是否存在。未解锁、未触发或仅用于组织结果的占位事件 MUST NOT 造成伤害、获得逐次命中伤害加算或消耗其次数；系统 MUST NOT 仅以零天赋倍率表达“没有命中”。

#### Scenario: 低命流浪者配云堇

- **WHEN** C0 至 C5 流浪者计算风行普攻单次命中且云堇领域有效
- **THEN** 云堇加算只进入实际存在的命中
- **AND** C6 风弹不出现为可造成伤害的事件

#### Scenario: 独立六段伤害的组织占位

- **WHEN** 一个 C6 指标由六次真实伤害组成，且申鹤冰翎适用于这些命中
- **THEN** 只有六次合格命中按明确的次数前提取得加算
- **AND** 不存在第七次由零倍率占位生成的冰翎伤害

#### Scenario: 卡齐娜 C6 与岩伤基础加算

- **WHEN** 卡齐娜计算已声明的 C6 护盾破裂伤害，叶洛亚的岩伤基础加算满足条件
- **THEN** 只有真实的200%防御力命中取得一次加算，零倍率组织事件不产生第二次伤害
- **AND** 指标已声明的 C4 防御状态进入真实命中的来源面板，而非只作用于组织事件

### Requirement: 角色追加事件具有显式增益资格

角色追加伤害 MUST 根据其自身的伤害类别、元素、适用的角色状态及明确继承关系计算，既不能漏掉本应适用的基础区/面板增益，也不能继承仅限父动作的无关增益。武器独立触发伤害 MUST 保持自身既有资格，不因角色修复获得全部父动作增益。

#### Scenario: 丝柯克协同普攻继承适用面板

- **WHEN** 丝柯克 C6 普攻协同攻击发生于已生效的 C2 攻击力状态，且云堇加算满足条件
- **THEN** 协同攻击读取适用的 C2 攻击力并计算其自身普攻加算
- **AND** 不把仅适用于另一类技能事件的加成混入该段

#### Scenario: 基尼奇炮类追加伤害继承 C1

- **WHEN** 基尼奇 C6 炮类追加伤害满足 C1 炮伤暴击伤害条件
- **THEN** 追加伤害与主炮均包含该 C1 暴伤来源

### Requirement: 触发概率加权完整事件

系统 MUST 先求出一次真实触发时的完整事件结果，再按该事件触发概率计算其期望；技能倍率、符合资格的固定伤害加算及其他同段项 MUST 使用一致的概率权重。多次独立命中不得因概率折算合并而改变逐段加算语义。

#### Scenario: 伊法 C6 的半概率普攻

- **WHEN** 伊法 C6 额外秘药弹以 50% 概率触发，并具有适用的云堇普攻伤害加算
- **THEN** 该加算产生的额外期望伤害为完整触发时对应贡献的 50%
- **AND** 不会遗漏加算，也不会按 100% 触发计算

### Requirement: 依赖效果以实际资格为准

依赖其他效果的伤害或增益 MUST 只在依赖项通过来源、命座、队伍条件、互斥和有效状态校验后生效。请求中的效果 ID 本身 MUST NOT 证明其已满足条件；互斥状态的子效果不得同时叠加。

#### Scenario: 遗留二层猎人心得选择

- **WHEN** 单人基尼奇请求中带有当前队伍不满足的二层猎人心得选择
- **THEN** 二层父效果及其依赖伤害均不生效，或请求被明确拒绝
- **AND** 不会在实际一层心得基础上额外叠入二层伤害

### Requirement: 前台互斥状态一致作用于所有关联增益

仅在某角色前台状态期间生效的增益 MUST 对精通、增伤、减抗和反应双暴遵守同一状态资格。另一个必须前台施放的目标动作 MUST NOT 同时受益于互斥的前台状态；满足条件的后台伤害不应被一刀切禁用。

#### Scenario: 奥黛塔前台动作与梦浮互斥

- **WHEN** 目标是奥黛塔前台破晓终奏，梦见月瑞希只是队友
- **THEN** 不应用必须梦见月瑞希正处于前台梦浮才有效的关联增益
- **AND** 独立于梦浮、且确实满足条件的队伍增益保持有效

#### Scenario: 来源属性转换保留实际动作归属

- **WHEN** 奥黛塔前台终奏读取队友梦见月持流浪的晚星的精通转攻击贡献
- **THEN** 计算梦见月来源精通时仍保留奥黛塔为实际动作所有者，不能因临时切换属性接收者而认定梦见月正在前台
- **AND** 梦浮 A4/10% 精通既不直接进入主角色面板，也不通过武器属性转换间接进入

#### Scenario: 未声明前后台资格的旧动作

- **WHEN** 队友增益要求来源在前台，但目标动作未声明前后台资格
- **THEN** 系统保守地不应用该增益，不将未知资格推定为后台
- **AND** 为经过审阅的真实后台动作声明资格后，该增益可以正常生效
