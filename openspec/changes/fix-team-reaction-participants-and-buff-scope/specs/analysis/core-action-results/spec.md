## ADDED Requirements

### Requirement: 反应星扩散完整参与者

反应星扩散 SHALL 使用所有已配置队员的独立贡献，不得提前排除第二名风元素或其他元素队员。风伤的 60% 位置 MUST 由风元素角色占据；冰风旋的 60% 与 30% 位置 MUST 分别为冰、风元素。其余位置按既有逐暴击组合规则选取，角色不重复占位，缺位计零，直接星扩散指标不改为全队加权。

#### Scenario: 双风双冰队伍
- **WHEN** 梦见月、珐露珊、奥黛塔和迪奥娜计算反应星扩散风伤
- **THEN** 四名队员均出现在贡献轨迹中，首位只选风元素角色，其余三位使用剩余队员

#### Scenario: 缺少冰元素
- **WHEN** 冰风旋场景无冰元素队员
- **THEN** 60% 位置为零，其他合格位置不前移补位
