# 实施与验收记录

日期：2026-09-10。实现基于主线 `6cc223f5162a98d05fa8fb7ba49c4d6a8aa4df96`。本文记录发布前验收，无用户数据迁移；实际发布状态以 Git 提交、远端版本和运行镜像核验为准。

## 已完成

- 全量与单候选共用候选构造、资格及场景求值；新增 `POST /v1/analysis/weapon-comparison`。局部请求只求基线与一个候选，完整 API 不再重复求基线。
- Web 单行加载、更新重排、失败恢复/重试，以及完整报告世代和逐武器请求隔离。旧响应不会覆盖新精炼、新指标或新场景；不同武器的响应独立合并。
- 再次完整计算保留此前成功选择的候选精炼，局部请求仍只发送单个候选，不携带全量覆盖表。
- 固定数据仓库复用 SQL statement，并使用总量 4096 项的实例级缓存。返回复合数据保持副本语义，缓存关闭后清理，不缓存用户场景。
- 多参与者星扩散复用真实动作来源映射，只重建参与者局部上下文。不同候选仍重算整队来源属性，不跳过团队武器影响。

## 数值与性能

Node `v22.22.0`；游戏数据 SHA-256 `98c3268bcd39d5608899a318bd29d09c58006469125b4e889d842006c61a24b5`。

复现脚本为 [benchmark.mjs](benchmark.mjs)，基准原始记录：[优化前](benchmark-before.json)、[优化后](benchmark-after.json)。每类先预热一次，再测三次取中位数；没有启用 CPU profiler。样本为非私人四人配置：梦见月 C6、奥黛塔 C0、珐露珊 C6、迪奥娜 C6，冰风旋等级 6。

| 工作 | 优化前中位数 | 优化后中位数 |
|---|---:|---:|
| 单指标 | 313.69 ms | 39.35 ms |
| 完整报告：46 武器、11 词条、2 成长项 | 22,663.97 ms | 2,936.63 ms |
| 千夜浮梦改为 R2 | 39,770.64 ms（全量重算） | 107.13 ms（局部） |

以上是本机代表样本，不是线上延迟承诺。前组全量样本波动较大（18.5–41.1 秒）；前组末尾精炼采样与开发构建有部分重叠，不宜用其加速倍数作为严格性能结论。确定性改善由调用次数验证：单候选仅两次场景求值，多参与者不再重复准备整队上下文。首次完整报告仍遍历所有候选，未引入任务队列或服务端计算取消。

数值通过深比较验证：普通直伤、风星扩散、冰风旋的完整求值对象（含事件、来源轨迹），以及完整报告所有武器、词条和成长项均完全一致。基线冰风旋 `23524.312914823335`；千夜浮梦 R2 `30212.49108472739`，提升比例 `0.2843091823391639`，前后相同。全量与局部响应的整体形状不同，因此不比较这两者的整个 JSON 摘要，而比较对应武器结果与基线。
