## MODIFIED Requirements

### Requirement: 可解释公式轨迹

每个已支持的伤害或辅助指标结果 MUST 返回与最终数值一致的类型化公式轨迹。多事件动作 MUST 可追溯到稳定事件标识；聚合展示可以聚焦代表事件，但不得改变完整动作总值。普通剧变反应获得专属暴击效果时，轨迹 MUST 展示反应暴击率、暴击伤害、暴击期望乘数及效果来源；未获得该效果时不得虚构暴击阶段。

#### Scenario: 展示多事件动作

- **WHEN** 所选动作声明了多个伤害事件和展示焦点
- **THEN** 系统返回各事件的稳定标识、数值和公式轨迹
- **AND** 聚合结果与事件求值使用同一权威数据

#### Scenario: 展示可暴击的普通扩散

- **WHEN** 梦见月瑞希 C6 的梦浮效果为当前普通扩散提供固定 30% 暴击率和 100% 暴击伤害
- **THEN** 该扩散的期望伤害乘数为 `1 + 30% × 100%`
- **AND** 轨迹将两项数值及“慕念萦心间”来源列在反应暴击阶段
- **AND** 系统不把角色面板双暴叠加到该固定反应双暴中
