## MODIFIED Requirements

### Requirement: 显式反应假设

增幅、激化、剧变及独立特殊反应 MUST 通过动作或事件的类型化声明进入对应公式。系统 MUST NOT 从队伍元素、动作名或未声明的触发历史猜测反应；独立特殊反应不得被错误套用普通直伤乘区。普通剧变反应 MUST 默认不能暴击；只有匹配当前来源、累计命座、动作和剧变反应种类的类型化效果，才能提供独立于角色面板的反应暴击率和暴击伤害。

#### Scenario: 求值已声明的蒸发动作

- **WHEN** 目标动作显式声明蒸发方向、反应加成和适用事件
- **THEN** 系统在正确公式阶段应用该增幅反应
- **AND** 直接结果与事件轨迹展示一致的反应前提和乘数

#### Scenario: 无暴击效果的普通剧变反应

- **WHEN** 目标动作声明普通剧变反应，但不存在匹配的反应专属暴击效果
- **THEN** 系统保持该反应不能暴击，并返回与变更前一致的期望伤害
- **AND** 系统不读取角色面板暴击率或暴击伤害来推断剧变反应暴击

#### Scenario: 命座效果允许指定剧变反应暴击

- **WHEN** 队伍中满足累计命座门槛的来源角色，为当前剧变反应提供固定反应暴击率和暴击伤害
- **THEN** 系统只对匹配的剧变反应应用这组独立暴击参数
- **AND** 不匹配的反应种类、低于门槛的来源配置以及普通直伤均不应用该效果
