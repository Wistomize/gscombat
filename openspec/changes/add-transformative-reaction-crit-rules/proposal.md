## Why

普通剧变反应当前被求值链路硬编码为不能暴击，导致梦见月瑞希 C6 已明确提供的“扩散固定 30% 暴击率、100% 暴击伤害”无法进入指标；只实现她的精通转双暴和星扩散双暴仍会向用户交付不完整的 C6。该工作因改变共享剧变反应公式及效果阶段而触发 OpenSpec。

## What Changes

- 为普通剧变反应增加类型化的反应专属暴击率和暴击伤害效果，默认值均为零，因此既有剧变反应结果保持不变。
- 剧变反应在存在专属暴击效果时，按 `1 + clamp(暴击率, 0, 1) × 暴击伤害`计算期望伤害；该乘区不读取角色面板普通双暴。
- 允许效果按剧变反应种类、来源角色和累计命座筛选，并在轨迹中明确列出暴击期望及其来源。
- 为梦见月瑞希 C6 声明梦浮期间全队普通扩散固定 30% 暴击率和 100% 暴击伤害；C0 至 C5 不应用该效果，C6 自动应用。
- 增加 API 级队伍集成测试，验证梦见月瑞希本人和队友的普通扩散均遵守同一规则，同时不影响星扩散或其他剧变反应。

### Non-goals

- 不改变月反应、星烁反应或普通直伤的既有暴击公式。
- 不实现完整技能持续时间、切人时序或循环模拟；最大可达场景把梦浮期间视为所选扩散指标的固定前提。
- 不在本变更中处理梦见月瑞希 C1 的多事件星扩散聚合，也不顺带补齐其他角色命座内容。
- 不让所有普通扩散默认暴击，也不从角色面板双暴推断剧变反应可以暴击。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `analysis/action-semantics`: 类型化动作效果可为指定普通剧变反应提供独立暴击率和暴击伤害。
- `analysis/core-action-results`: 核心动作结果在剧变反应获准暴击时返回对应期望伤害和可解释暴击轨迹。

## Impact

- 影响 `packages/content` 的动作效果目标类型与梦见月瑞希角色声明。
- 影响 `packages/analyzer` 的效果解析、剧变反应求值输入和轨迹组装。
- 影响 `packages/calculator` 的剧变反应事件公式，但无效果时必须保持当前数值。
- `apps/api` 仅复用现有 `/v1/analysis` 请求与响应；预计不新增必填字段，不改变 HTTP 兼容承诺。
- 不涉及持久化迁移、鉴权、安全边界或新外部依赖。
- 实现完成后需要常规构建和部署；本提案本身不授权提交、推送或部署。
