## Why

当前命座声明虽然以 `minimumSourceConstellation` 表达累计解锁，但若干用户可见指标仍通过“只计 C6 的一部分”“追加段不继承技能类别效果”或“当前类型无法表达治疗”规避完整语义。这会让同一 C6 Build 遗漏 C1 至 C5、固有天赋、技能类别增益或 C6 自身的数值，并使 C6 专属指标在低命座配置中仍可被选择。

本变更因修改共享伤害事件、辅助指标与公开 Catalog 的语义和数据形状而触发 OpenSpec。目标是补齐可复用能力并迁移现有命座内容，不建立角色专用求值器或第二条计算链路。

## What Changes

- 让角色命座产生的独立伤害段声明自身的普攻、重击、下落、战技或爆发身份，并在独立求值时继承符合该身份的角色、队伍、武器和圣遗物效果。
- 允许动作内事件和指标声明最低来源命座；C6 Build 自动包含 C1 至 C5，低命座 Build 不求值命座事件，也不把不可用指标作为可选目标。
- 扩展同段伤害项，使其能按命座解锁、读取动作场景参数，并在正确顺序与原动作倍率组合，覆盖生命之契等动态倍率。
- 扩展治疗指标，使独立命座治疗、额外来源属性项、上限以及受益方治疗加成可在同一类型化公式中表达。
- 迁移所有已审计的现有 C6 数值效果，补齐其累计低命座、固有天赋和技能类别效果；只影响频率、冷却、能量、移动或减伤而不改变所选单次指标数值的命座，不伪造伤害倍率。
- 增加系统级审计与端到端回归，禁止 verified 指标在说明中以类型能力不足为由排除会改变其数值的命座效果。

### Non-goals

- 不模拟完整循环、命中频率、冷却重置、能量循环、多目标选择或玩家操作时序。
- 不把只改变次数/持续时间而不改变当前单次指标的命座强行折算成伤害。
- 不改变已确认的普通反应、月反应或星反应乘区公式。
- 不提交、推送或部署代码；这些动作仍需用户另行明确授权。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `analysis/action-semantics`: 命座事件、独立追加段与同段动态倍率保留累计命座和技能类别语义。
- `analysis/core-action-results`: 指标列表与结果必须匹配当前 Build 命座，治疗和伤害轨迹完整包含适用命座贡献。
- `content/authoring-contract`: verified 内容不得通过说明性排除跳过会改变当前指标数值的累计命座效果。

## Impact

- 影响 `packages/content` 的动作、事件、效果和指标声明类型及现有角色内容。
- 影响 `packages/analyzer` 的事件编译、效果筛选、治疗求值、Catalog 投影和完整性审计。
- 仅在需要把最低命座暴露给客户端时，以向后兼容可选字段影响 `packages/contracts`、`apps/api` 与 `apps/web`；旧工作区和分析请求不新增必填字段。
- 不修改持久化 schema，不需要数据迁移；现有 Build 的 `constellation`继续是唯一命座事实来源。
- 不涉及鉴权、安全策略或外部网络。
- 回滚可先移除迁移后的内容声明，再撤销尚无调用者的可选类型字段；没有不可逆数据变更。
