## MODIFIED Requirements

### Requirement: 动作相对事件时间线

多事件动作 MUST 以动作施放为零点声明持续时间，并为每个伤害事件声明稳定标识、发生时间、伤害部分和 `cast`、`hit` 或显式时间快照策略。事件可声明来源角色最低/最高命座与自身技能类别；系统 MUST 以来源 Build 的累计命座过滤事件，并以事件声明的类别匹配适用效果。任一未声明的事件类别维度不得从触发动作继承。未提供时间线或新字段的旧声明 MUST 保持原行为。

#### Scenario: 求值带延迟命中的动作

- **WHEN** 一个动作声明了施放后发生的多个事件及各自快照策略
- **THEN** 系统按事件时间顺序求值，并在每个事件使用其声明的统计快照
- **AND** 事件轨迹保留稳定标识与命中次数

#### Scenario: C6 角色求值 C1 事件与 C6 追加段

- **WHEN** 来源 Build 为 C6，动作包含最低 C1 和最低 C6 的事件，且 C6 追加段声明为战技伤害
- **THEN** 两个事件都参与求值
- **AND** C6 追加段获得适用于战技伤害的角色、队伍、武器与圣遗物效果

#### Scenario: 低命座排除未解锁事件

- **WHEN** 来源 Build 的命座低于事件声明门槛
- **THEN** 系统不求值、不展示且不计入该事件

#### Scenario: 高命座替换原有事件

- **WHEN** 一个高命座把原有伤害事件替换为另一种公式，且旧事件声明最高来源命座
- **THEN** 低命座只求值旧事件，高命座只求值替代事件
- **AND** 系统不得把替代事件错误叠加在被替换的旧事件上

#### Scenario: C1固定倍率与事件倍率共同作用

- **WHEN** 一个动作事件包含天赋倍率与最低C1的固定属性倍率，且该事件还有自身倍率
- **THEN** C0只把自身倍率应用于天赋项，C1及以上把自身倍率应用于天赋项与固定项之和
- **AND** 固定项保留来源命座和倍率证据，不得被改写为普通增伤

### Requirement: 显式反应假设

增幅、激化、剧变及独立特殊反应 MUST 通过动作或事件的类型化声明进入对应公式。角色追加段若声明不继承触发动作反应，MUST 作为自己的无反应事件求值；系统 MUST NOT 从触发动作、队伍元素或动作名猜测反应，也不得把特殊反应套入普通直伤乘区。

#### Scenario: 求值已声明的蒸发动作

- **WHEN** 目标动作显式声明蒸发方向、反应加成和适用事件
- **THEN** 系统在正确公式阶段应用该增幅反应
- **AND** 直接结果与事件轨迹展示一致的反应前提和乘数

#### Scenario: 无反应命座追加段由蒸发动作触发

- **WHEN** 一个蒸发动作触发声明为无反应的角色命座追加段
- **THEN** 原动作按蒸发公式求值
- **AND** 追加段不复制蒸发倍率，但仍获得其明确技能类别适用的普通伤害效果

### Requirement: 派生效果使用已解析属性

需要读取队伍或触发动作属性的效果 MUST 使用当前配置在该效果应用前的已解析终值。队伍最高元素精通效果 MUST 比较全部已配置队员而非默认使用效果来源；按来源最终元素精通换算的队伍精通分享 MUST 同时读取不含同类分享的快照，且其他伤害换算 MUST 读取分享后的最终精通；暴击触发追加段 MUST 使用原动作最终暴击率作为触发概率，并将该概率限制在 `0..100%`。系统 MUST NOT 以角色常量或未封顶的面板暴击率替代这些终值。

#### Scenario: 队伍最高元素精通由其他队员提供

- **WHEN** 一个前台元素精通分享效果声明读取队伍最高最终元素精通，且最高值来自效果来源以外的队员
- **THEN** 系统使用该队员的已解析最终元素精通乘以声明比例并应用上限
- **AND** 分享结果只进入当前所选前台角色的元素精通

#### Scenario: 暴击触发追加段使用动作最终暴击率

- **WHEN** 一个追加段声明以原动作最终暴击率作为触发概率
- **THEN** 系统先解析原动作全部适用暴击率来源，再以 `min(max(最终暴击率, 0), 1)` 求得触发概率
- **AND** 超过 100% 的暴击率不再提高触发概率，追加段仍按自身可暴击声明单独计算暴击期望

#### Scenario: 最终精通分享不递归放大

- **WHEN** 队伍中一个或多个效果按来源角色最终元素精通分享元素精通
- **THEN** 每项分享都从不含同类分享的来源精通快照计算，再一次性加入受益方
- **AND** 依赖最终元素精通的伤害或增伤效果读取分享后的数值，分享效果之间不得循环或重复套用
