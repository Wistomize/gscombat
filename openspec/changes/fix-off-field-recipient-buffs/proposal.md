## Why

莉奈娅点按 E 的后台持续月结晶伤害错误获得五郎大将旗指物的前台固定防御加成。两个 E 指标均未声明站位，且当前通用效果模型只约束 Buff 来源站场，不能表达受益角色站场；仅修改指标名称或添加后台标签无法修复数值。

## What Changes

- 增加可复用的“受益角色须在前台”效果限制，与“来源角色须在前台”明确分离。
- 将莉奈娅点按加力重锤设为后台单次月结晶伤害，名称添加“（后台）”；连续点按百万吨重锤设为前台单次月结晶爆发，名称添加“（前台）”。保留原指标 ID 和倍率。
- 五郎旗帜固定防御及同领域岩伤限前台；不畏风雨的全队 25% 防御与 C6 已声明的队伍效果不受此限制。
- 数值、属性来源轨迹、武器比较和角色来源属性换算保持同一站位语义；手动选中不绕过限制。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `analysis/action-semantics`: 增加基于指标站位的受益 Buff 资格约束及莉奈娅两个核心动作的站位语义。

## Impact

- OpenSpec 触发项：共享效果模型及通用效果资格判断变化。实现涉及 `packages/content`、`packages/analyzer`；API 和 Web 消费既有结构，仅验证契约和展示。
- 不改变 HTTP Schema、配置版本、保存的指标 ID 或数据库；无迁移、安全变化、新依赖。
- 非目标：不扩展完整切人/延时残留/动态快照模拟，不新增连续点按后普通岩伤指标或将其混入月结晶合计，不批量重写其他角色内容。
- 保留上轮未提交的武器修改及无关图片。未经额外授权不提交、推送、部署、归档。
