## ADDED Requirements

### Requirement: 生产启动必须使用显式有效的凭据及持久化配置

运行在生产模式的 API MUST 在接受请求前确认：会话密钥由调用配置或部署环境显式提供，非空白且不少于 32 个字符，
不是项目公开的开发默认值或部署示例占位值；工作区位置为显式提供的非空文件型数据库路径，不是临时或内存数据库。
系统 MUST NOT 因配置缺失或显式值无效而静默采用开发默认值。

#### Scenario: 生产缺少密钥

- **WHEN** 生产调用方未提供会话密钥，但提供了合法工作区路径
- **THEN** API 拒绝启动，指出缺少有效密钥
- **AND** 不开始接受请求，不创建或修改工作区文件

#### Scenario: 显式提供公开默认值或无效值

- **WHEN** 生产调用方提供空白、少于 32 字符、开发默认密钥或部署示例占位密钥
- **THEN** API 拒绝启动，即使另一个配置来源包含可用值也不掩盖高优先级无效值
- **AND** 错误信息不包含提供的密钥

#### Scenario: 生产未配置持久工作区

- **WHEN** 生产调用方未提供工作区路径，或显式选择空白、临时或内存数据库
- **THEN** API 拒绝启动，不自动创建临时替代库
- **AND** 已有工作区数据不变

### Requirement: 合法生产配置必须保留既有凭据及数据身份

使用合法显式配置启动时，系统 MUST 保留密钥原值及工作区数据身份，不自动轮换密钥、不更改凭据派生算法、
不重建已有用户数据；HTTP 请求及响应契约保持原样。

#### Scenario: 生产服务使用已有工作区重启

- **WHEN** 生产服务沿用原有有效密钥与原工作区文件启动
- **THEN** API 可以就绪，原邀请码和未过期会话继续有效
- **AND** 已保存配置及 revision 不被清空或重置

### Requirement: 开发便利配置不得扩散到凭据管理流程

非生产 API SHALL 继续允许显式内存工作区及未指定配置时的开发默认值；显式配置优先级 MUST 保持调用配置高于环境变量。
邀请码管理流程 MUST 始终要求显式有效密钥及文件型工作区，不能以开发默认回退创建凭据。

#### Scenario: 未配置环境变量的本地 API

- **WHEN** 开发或测试调用方没有提供密钥和工作区路径
- **THEN** 本地 API 仍可使用便利默认值启动并关闭
- **AND** 不要求开发者创建实际生产工作区

#### Scenario: 管理命令缺少持久化配置

- **WHEN** 管理邀请码时未提供显式有效密钥或文件型工作区路径
- **THEN** 管理流程拒绝操作，不输出新邀请码，不打开内存替代库

### Requirement: 启动失败必须释放资源且不暴露凭据

必要启动配置校验失败时，系统 MUST 不取得数据库资源；后续资源初始化或监听失败时，系统 MUST 释放此前成功取得的资源。
命令行启动失败 MUST 以非零状态结束，并提供不包含秘密值的可操作错误说明；释放失败不得掩盖最初的失败原因。

#### Scenario: 配置无效且数据库位置不可用

- **WHEN** 启动配置无效，同时游戏数据库位置也不可用
- **THEN** 失败原因为配置无效，而不是读取数据库失败
- **AND** 不创建工作区文件

#### Scenario: 后续数据库初始化失败

- **WHEN** 前一个数据库成功打开，后一个数据库打开或初始化失败
- **THEN** 服务不就绪，已经打开的连接被释放
- **AND** 不回退到空白库，也不修改现有用户文档

#### Scenario: 监听失败

- **WHEN** 服务初始化成功，但监听地址或端口不可用
- **THEN** 启动以非零状态结束，并释放已取得的数据库资源
- **AND** 不留下继续持有资源的应用实例
