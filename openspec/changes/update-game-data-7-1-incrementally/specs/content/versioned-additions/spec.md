## ADDED Requirements

### Requirement: 固定伤害辅助指标

系统 SHALL 优先展示沃雅妮莎单次水冰基础伤害加值和星扩散固定伤害加值，保留治疗及伤害指标。

#### Scenario: 辅助指标与实际注入一致

- **WHEN** 在相同配置及增益下查看辅助指标和相应伤害轨迹
- **THEN** 两者采用相同来源生命值、40000起算阈值、倍率和上限
- **AND** 不将单次加值乘以领唱或重唱层数

#### Scenario: 装备依赖冻结的来源面板

- **WHEN** 队伍装备效果声明依赖目标冻结状态
- **THEN** 伤害和辅助配置页面显示同一个冻结开关，并将其传递至来源面板准备
- **AND** 漩流颂歌增强后的生命值同时用于辅助加值和实际伤害注入
- **AND** 不要求前端硬编码武器 ID

### Requirement: 增量来源与实体维护

系统 MUST 保留已有快照事实及原来源，只为本版本新增和经核实更正的数据记录新来源，不以补齐另一数据源全库映射为前提。

#### Scenario: 更新到 7.1

- **WHEN** 导入两名新角色和六把新武器
- **THEN** 原有魔女天赋和装备数值保持不变
- **AND** 新数据可追溯到固定提交和校验和

### Requirement: 新增内容沿用正式计算链路

系统 MUST 使用相同规则计算实际装备和武器替换，按角色命座累计应用天赋等级和相应增益。

#### Scenario: 相同武器比较

- **WHEN** 候选武器、精炼和当前装备相同
- **THEN** 伤害相同且收益为零
- **AND** 前台限定增益不会给予后台受益者
