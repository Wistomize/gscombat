## ADDED Requirements

### Requirement: HTTP 失败使用统一公开错误形状

API 的结构校验失败、领域请求错误、版本冲突、资源限制、上游失败和内部异常 MUST 使用既有 `{ code, message }`
错误形状。服务端 MUST 提供非空机器错误码与可读提示，不把内部异常文本、堆栈、SQL 或凭据原样返回。
已发布的会话/工作区业务错误码与状态 MUST 保留；成功响应和访客权限保持不变。

#### Scenario: 请求不符合输入结构

- **WHEN** 请求缺少必填字段或提交非法 JSON
- **THEN** API 返回 HTTP 400 和可读的结构错误提示
- **AND** 响应包含 code/message，不暴露输入载荷或内部堆栈

#### Scenario: 请求不存在的资源入口

- **WHEN** 调用方访问未注册的 API 路径
- **THEN** API 返回 HTTP 404 和统一错误形状

#### Scenario: 已有会话业务错误

- **WHEN** 工作区会话失效，或工作区写入使用陈旧 revision
- **THEN** API 分别保留现有 401/409 与业务错误码
- **AND** 不改变有效会话的隔离、Cookie 或保存数据

### Requirement: 领域错误和内部故障必须明确区分

领域请求错误 MUST 由明确的错误类别识别，不依赖匹配异常消息的文字；领域库 MUST 不承诺 HTTP 状态码。
非法字段关系返回 HTTP 400，场景与计算版本不一致返回 HTTP 409。未知异常、缺失维护数据、非法内容声明及
计算不变量破坏 MUST 保留为内部故障，不因包含某些关键词或未经识别的 statusCode 就被当作输入错误。

#### Scenario: 非队员被指定为前台

- **WHEN** 请求的前台角色标识不属于当前队伍
- **THEN** API 返回 HTTP 400 和 invalid_field_presence 错误
- **AND** 伤害、核心报告和辅助指标入口采用相同错误分类

#### Scenario: 内部声明损坏

- **WHEN** 合法请求遇到缺失技能绑定、固定数据异常或未分类的内部异常
- **THEN** API 返回 HTTP 500 和 internal_error
- **AND** message 为含请求编号的通用提示，不泄露原始内部异常

### Requirement: 请求和候选失败必须可关联且不泄露个人配置

API MUST 为响应提供服务端生成的请求标识，并将内部失败与请求标识关联。候选部分失败 MUST 可经计算标识、
候选标识关联至服务端诊断。日志 MUST 仅记录允许的分类、状态、代码位置和关联标识，MUST NOT 记录
请求/响应整包、邀请码、Cookie、授权头、UID、原始 Build 标识或原始异常文本/堆栈。
正常输入拒绝和用户取消 MUST 不被记录为内部 500。

#### Scenario: 内部异常的用户报告

- **WHEN** 一个请求触发内部异常
- **THEN** 响应 X-Request-Id 与内部诊断可相互关联
- **AND** 公开提示中的请求编号可用于定位同一次失败

#### Scenario: 套装候选失败

- **WHEN** 同一计算的某候选求值失败，且请求仍可得到部分比较结果
- **THEN** 日志可通过计算标识和候选标识定位失败，并关联收到该结果的请求标识
- **AND** 不记录整份场景、完整任务键或原始异常文本

### Requirement: 可识别的外部展示柜失败不能伪装为引擎错误

展示柜上游请求的网络失败、非预期 HTTP 结果和无法解析的外部响应 MUST 与内部计算错误区分。
上游不存在目标返回 HTTP 404、上游限流或明确不可用返回 HTTP 503、上游超时返回 HTTP 504，
其他可识别上游请求/响应故障返回 HTTP 502。内部归一化代码错误 MUST NOT 被笼统降为上游故障。
既有不支持角色/装备的逐项跳过和合法空结果 SHALL 保持现有协议。

#### Scenario: 上游超时

- **WHEN** 展示柜请求超过现有上游超时预算
- **THEN** API 返回 HTTP 504 与 showcase_timeout
- **AND** 提示不含原始 UID、上游响应体或请求凭据

#### Scenario: 合法响应含不支持条目

- **WHEN** 外部响应结构合法，但包含当前不支持的角色或装备
- **THEN** 系统沿用原有逐条跳过协议
- **AND** 不将整次合法导入改为 502
