# ARCH-013 抛错来源清单

2026-10-19，实施前按实际条件分类，不使用消息关键词分类或整文件替换。

| 入口/位置 | 用户输入错误 | 仍属内部故障 |
|---|---|---|
| core/build-variant | Build 契约、缺失/错选旅行者变体、动作与所选变体冲突 | 非旅行者动作声明旅行者元素、声明固定参数所有者冲突、快照元素非法 |
| core/field-presence | 前台不是队员、与动作站位冲突 | 不改实际站位求值 |
| scenario/evaluate | 请求版本不符、未注册/错属动作、命座不足、非法 Build | 未注册求值器、底层数据/内容不变量 |
| metrics/evaluate/runtime/damage/scalar | 指标身份/命座、缺少场景/受益人/月兆状态、重复队员、非法手填生命/受疗/范围条件、非法显式装备来源 | 指标引用缺失动作/倍率/快照、内容引用无法求值 |
| effects/dependent-effects | 未注册的显式状态 ID | 已注册状态同时包括数值效果、角色 scenarioEffectOptions 和 requiredActiveEffectIds，不能把合法激活状态当作不存在的数值效果 |
| evaluators/scenario-parameters | 手填未知参数、非法值/联动上限、输入命座门槛 | 重复参数声明、非法默认/范围、缺失联动映射 |
| effects/action-effects | 显式来源、互斥、命座和来源选择不合法 | HP/精通转换/同段加值被声明给错误拥有者 |
| effects/active-element-overrides | 显式重复/重叠、缺失/多重来源、来源命座不足 | 动作时长、快照时长、参数/数据缺失 |
| effects/weapon-state | 显式来源、组选项、冲突状态；迁移已有 statusCode=400 | 不改变自动准备或数值规则 |
| analysis/analyze/equipment-session/artifact-comparison | 既有精炼、武器/套装候选与显式套装选项拒绝 | 平均值空输入、分类不等价、无主词条分配、非有限伤害 |
| API 资源路由/效果选项 | 不支持的指标种类/来源、未知候选/选项 | 已声明为辅助却得到伤害等内部不变量 |
| API 调度/比较服务 | 409 版本、429 容量、503 预算/关闭、499 取消 | 合法基准生成的候选异常保留部分失败，不直接归咎用户 |
| Enka 外部调用 | 404 不存在、503 上游限制/不可用、504 超时、502 网络/异常响应 | 本地 URL 配置、归一化程序错误；合法跳过不是异常 |

补充边界：自动候选中即使出现 AnalysisInputError，显式选择已经通过前置校验后也按该候选内部失败处理。
日志只接收分类、代码位置和计算/候选/请求标识，不序列化用户数据和原始异常。
