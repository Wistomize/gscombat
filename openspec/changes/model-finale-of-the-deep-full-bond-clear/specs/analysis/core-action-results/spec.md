## MODIFIED Requirements

### Requirement: 同一场景的反事实比较

系统 MUST 通过重算同一权威场景来计算武器、成长项和圣遗物词条收益。每次比较只可替换被声明的干预项，其他 Build、队伍、敌人、动作和条件 MUST 保持不变。候选武器的可达满效果若由候选 Build 的最终属性派生，系统 MUST 在替换武器并解析该候选 Build 后计算其实际贡献，不得直接套用与角色属性无关的固定上限。一个候选武器在当前可达满状态所需分支已完整建模时，系统 MUST 允许其参与比较，不得仅因当前产品明确排除的中间状态未建模而隐藏整把武器。

#### Scenario: 比较候选武器

- **WHEN** 系统为当前主角色评估一个兼容候选武器
- **THEN** 系统使用候选武器替换原武器并重新执行同一场景
- **AND** 增益比例以重算结果与基线核心动作结果的差异计算

#### Scenario: 计算海渊终曲完整清除生命之契的收益

- **WHEN** 单手剑角色在 `maximum_reachable` 装备效果模式下比较海渊终曲
- **THEN** 系统视为已施放元素战技、治疗量充足，并完整清除等于候选 Build 最终生命值上限 25% 的生命之契
- **AND** 精炼 1 至 5 的平面攻击力分别按 `min(最终生命值 × 25% × [2.4%, 3.0%, 3.6%, 4.2%, 4.8%], [150, 188, 225, 263, 300])` 计算
- **AND** 该动态平面攻击力与施放元素战技后的攻击力百分比效果共同进入同一场景重算
- **AND** 武器更换收益结果包含海渊终曲及其当前精炼等级对应的结果

#### Scenario: 最终生命值不足以达到平面攻击力上限

- **WHEN** 精炼 1 海渊终曲的候选 Build 最终生命值为 20000
- **THEN** 系统将生命之契完整清除量计算为 5000
- **AND** 平面攻击力贡献为 `min(5000 × 2.4%, 150)`，即 120，而不是无条件取 150
