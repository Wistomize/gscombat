## Why

海渊终曲虽然已经声明施放元素战技后的攻击力提升和清除生命之契后的平面攻击力，但覆盖账本仍因“部分清除生命之契”未建模而将整把武器排除在公开目录与武器对比之外。这与当前产品对装备效果采用“可达满效果”的反事实比较语义不一致，也使本可由现有最终生命值派生能力准确计算的武器无法参与比较。

本变更触发 OpenSpec 的原因是它会修改武器反事实比较的计算语义与候选发布行为。受影响工作区为 `packages/content` 和 `packages/analyzer`；`apps/api` 与 `apps/web` 只通过既有契约展示变化后的目录与分析结果。

## What Changes

- 海渊终曲在施放元素战技后的可达满状态中，按装备者当前场景的最终生命值上限生成等于其 25% 的生命之契。
- 当前模型假设治疗量充足且该次生命之契被完整清除；清除后的平面攻击力按 `min(最终生命值 × 25% × 精炼系数, 精炼上限)` 计算。
- 精炼 1 至 5 的清除量系数分别为 2.4%、3.0%、3.6%、4.2%、4.8%，平面攻击力上限分别为 150、188、225、263、300；施放元素战技后的攻击力百分比效果保持现有规则。
- 海渊终曲在覆盖账本中不再因为当前产品不支持任意部分清除量而被整体隔离，并进入单手剑角色的配置目录和武器更换收益比较。
- 在 `maximum_reachable` 装备效果模式下，武器对比自动应用上述完整清除状态，并使用替换武器后的同一权威场景重算结果。
- 非目标：不增加治疗模拟、生命之契随时间变化、任意清除比例输入、治疗受限失败状态或完整战斗循环；不改动其他生命之契武器与角色机制。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `analysis/core-action-results`：明确基于候选 Build 最终属性、并采用可达满状态的武器效果如何进入同场景反事实比较。

## Impact

- `packages/content`：更新海渊终曲的类型化效果声明、效果说明、覆盖账本状态与聚焦测试。
- `packages/analyzer`：复用现有最终生命值派生与封顶值解析链路，并补充武器对比和公式结果的集成验证；预计不需要新增公共类型或计算分支。
- `apps/api`、`apps/web`：不改变 HTTP 或前端数据结构；既有目录将新增海渊终曲，武器更换收益将返回其动态计算结果。
- 兼容性：无破坏性 API 变化，无工作空间数据迁移；此前已保存的海渊终曲配置可继续沿用。
- 安全性：无鉴权、存储或外部输入边界变化。
- 部署：需要重新构建 Content、Analyzer、API 与 Web 镜像后才会在公网生效；本提案不包含提交、推送或部署操作。
