# 武器比较默认效果审计

日期：2026-09-10。代码基线：`2bcf013`。结论来源：实际 `listCombatActionEffects()` 注册结果、各武器 `effects.ts`、`getCandidateActiveEffects` 和 `addMaximumReachableEquipmentEffects`。

## 已确认的代码问题

1. 显式选择效果存在于 54 把武器；其中只有赦罪（克洛琳德）、赤月之形（阿蕾奇诺）有比较默认声明。这个数量包括三星武器，不能表述为“武器比较漏了 54 把”。
2. `selectionMode: optional` 会被 maximum_reachable 自动选择跳过。下面列举的是这些可选部分默认不启用，不代表该武器基础属性或其他自动效果都没有实现。
3. 遗祀玉珑效果已经实现，但没有比较默认声明。上轮真实梦见月测试中，精炼 5 默认比较为 24428.709854068522；显式打开生命 64% 和精通 80 后为 25971.745010157436。这是测试配置，不是用户当前配置。
4. 比较默认当前逐条清空整个互斥组，因此如果直接给遗祀玉珑两个贡献都加默认标记，后一条会覆盖前一条。同一状态多贡献需要成组选择。

## 本轮确认并实施的范围

以下十把来自上一条最终回复的表格，已获用户确认；不是下方完整审计表的全部武器。

| 武器 | 本轮规则 |
|---|---|
| 遗祀玉珑 | 比较默认有效窗口，生命与精通同组同时保留 |
| 纯水流华 | E 增伤和充分治疗清除 24% 最终生命上限的契；连续计算追加增伤并按精炼封顶 |
| 浪影阔剑、静谧之曲 | 用户明确默认已受疗；maximum_reachable 与比较一致 |
| 万国诸海图谱 | 明确反应动作或基线实际触发反应时比较默认预存两层 |
| 万世流涌大典、金流监督 | 分别限定那维莱特、莱欧斯利，比较默认三层，保留动作过滤 |
| 静水流涌之辉 | 芙宁娜自身变化三层；有其他队友时额外采用队友变化两层 |
| 暗巷猎手、虹蛇的雨弦 | 明确后台指标比较默认有效；补齐五个弓角色的常规后台动作标记 |

旧纯水流华部分清契 ID 保留兼容：主场景明确选择时保留；比较时完整清除默认替换同组旧状态，不叠加。其他名单外武器仍保持现状；不推导四风满层、击杀、低血、护盾等未确认状态。

## 原始优先处理建议（审计快照）

本表保留修改前的建议，不是全表实施清单；实际批准范围见上方。没有把角色名或“队伍里有某元素”当成完整实战触发证明。

| 武器 | 默认未启用的部分 | 建议的边界 |
|---|---|---|
| 遗祀玉珑 | 生命与精通同时加成 | 已要求比较默认启用；假设后台超过 5 秒，登场未满 10 秒，不保证长站场覆盖 |
| 纯水流华 | E 后基础元素增伤，以及清除生命之契后追加增伤 | 第一部分在施放 E 后的指标中容易满足；第二部分必须分开，按实际清除量计算，不能无条件取 6000 点 |
| 万国诸海图谱 | 反应后最多两层元素增伤 | 常规反应输出角色可以讨论默认两层；不能把本次第一次反应倒灌到触发它的命中，也不能凭队友能反应就认为持有者已触发 |
| 万世流涌大典 | 三层重击增伤 | 那维莱特正常生命变化后的重击优先补默认；不能对所有法器持有者一概满层 |
| 金流监督 | 生命变化后三层普攻、重击及当前声明的星超导增伤 | 莱欧斯利常规输出优先讨论；其他角色须有生命变化来源，星反应新增条款还需对应当前数据复核 |
| 静水流涌之辉 | 自身生命变化的战技增伤、队友生命变化的生命加成 | 芙宁娜常规战技输出优先讨论；自身/其他队友两类条件不能混为一条 |
| 浪影阔剑 | 受到治疗后攻击加成 | 有实际治疗到持有者的场景默认启用较合理；不能只凭名单里出现奶妈推断已经触发 |
| 静谧之曲 | 受到治疗后伤害加成 | 与浪影阔剑同类，需确认持有者受疗 |
| 苇海信标 | E 命中后攻击、受伤后攻击、无盾生命 | E 命中后部分较容易；受伤与无盾分别判断，不默认一起开 |
| 尘世之锁、斫峰之刃、贯虹之槊、无工之剑 | 命中叠层攻击（无盾/有盾各一组） | 常规连续命中可讨论默认叠层；护盾翻倍必须取实际护盾状态，不能默认有盾 |
| 暗巷猎手、虹蛇的雨弦 | 后台叠层/后台命中增益 | 后台输出指标适配；不能用于任意前台动作并声称一直满额 |
| 息灾 | E 后前台/后台圆顿攻击 | 优先拆开前后台判定，后台翻倍不可套在前台指标 |
| 柔灯挽歌 | 燃烧相关叠层增伤 | 燃烧场景下可考虑，不是任意配队默认 |
| 撼地者、拾慧铸熔、白辰之环 | 指定反应后的加成 | 分别核实队伍或持有者触发要求、反应类型和受益元素后适配 |
| 香韵奏者 | 后台攻击、治疗后自身及受疗角色攻击 | 分别核实持有者位置与受疗对象，不混同 |
| 白雨心弦 | 弦契层数生命与满层爆发暴击率 | 希格雯等适配角色可讨论；现有标签写成“生命之契”也应单独核实，不据此判定机制 |
| 厄水之祸、祭星者之望、钟剑 | 护盾条件增伤/暴击 | 仅护盾状态明确时适配；“有盾角色”不等于当前有效护盾 |
| 匣里灭辰、匣里龙吟、雨裁 | 目标元素附着增伤 | 按所选目标附着场景适配，不能只凭队伍元素判断 |

## 保持手动或另行确认

- 四风原典：满层需要站场时间，不能把“容易获得一层”当成“容易吃满”。
- 阿莫斯之弓、缀花之翎：箭矢飞行/瞄准时间不是任意动作都满足。
- 试作澹月：命中要害且已经触发；目标不一定有弱点。
- 黑岩绯玉、黑岩长剑、黑岩刺枪、黑岩斩刀、黑岩战弓：需要击败敌人，默认木桩不能假设先杀三个敌人。
- 狼的末路：低血敌人触发，不能默认整个战斗全程存在。
- 护摩之杖：半血额外攻击需要角色状态，不无条件开启。
- 聊聊棒：自身受到元素附着，与敌人附着、队伍元素不同。
- 流浪乐章：保留用户选择登场主题，不把三个随机结果叠加或擅自挑最优。
- 「究极霸王超级魔剑」：按用户此前决定保留任务进度 Buff。
- 弹弓：按用户此前决定保留命中时机必选，不扩大当前候选星级范围。
- 赦罪、赤月之形：已有指定角色默认，保持不变。
- 其余三星显式效果：黎明神剑、铁影阔剑、冷刃、沐浴龙血的剑、魔导绪论、鸦羽弓、甲级宝珏、神射手之誓、信使。分别涉及血量、敌人附着、击杀或要害；当前比较只枚举四/五星，不能把它们计入当前对比缺失数量。
