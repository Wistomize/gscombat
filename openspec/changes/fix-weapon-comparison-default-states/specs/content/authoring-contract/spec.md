## ADDED Requirements

### Requirement: 装备比较默认状态的声明

装备内容 MUST 显式声明比较默认状态适用于所有合法持有者还是指定角色。未声明默认的手动效果 MUST 保持原有选择语义；同一受益者的一个互斥组 MUST NOT 存在两个不同的适用默认状态。同一默认状态可以同时贡献多个属性，这些贡献 MUST 被完整保留。

#### Scenario: 适用于所有合法持有者

- **WHEN** 遗祀玉珑声明了适用于所有合法持有者的比较默认状态
- **THEN** 已维护或未来新增的合法法器角色不需要追加角色白名单即可应用该状态
- **AND** 不因此允许其他武器类型角色装备法器

#### Scenario: 保留角色限定语义

- **WHEN** 候选使用赦罪的现有克洛琳德限定默认，或赤月之形的现有阿蕾奇诺限定默认
- **THEN** 仅对原先指定的角色应用默认，不扩散到其他持有者

#### Scenario: 检查冲突默认

- **WHEN** 同一角色适用的装备声明把同一互斥组的两个不同状态同时标成默认
- **THEN** 内容校验报告可定位的冲突，而不是根据声明顺序悄悄选取其一
